# Prayagraj Open World

An open-world multiplayer game set on the **real map of Prayagraj**: the Sangam, the Ganga and Yamuna, Saraswati Ghat, real streets, bridges and about 5,600 real building outlines.

- Walk or drive (SUV or sedan), cross the raised bridges, explore the sand banks where the rivers meet
- In-game phone: map, missions with coins, chat, garage, wallet, camera
- Multiplayer: friends see you walking or driving
- Day and night, reflective river, golden-hour lighting; Lite mode for low-memory phones

## Run it
```
npm install
npm start
```
Open http://localhost:3000

Optional: set `MONGODB_URI` so the prepared map is saved between restarts.
